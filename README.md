# impacts-of-conurbation-within-jbmur
By applying remote sensing and utilising Landsat imagery through Google Earth Engine, this study will examine the impacts of conurbation within Jakarta Bandung Mega Urban Region (JBMUR) by identifying the following components:
1) Normalized Difference Vegetation Index (NDVI) and Normalized Difference Built-Up Index (NDBI)
2) Land Use Land Cover (LULC) classification using Random Forest algorithm 
3) Land Surface Temperature (LST) based on thermal band
4) Correlation between LST with NDVI and NDBI

This study will analyse those components within three different timeframes, which consists of the year of 2000, 2009, and 2019. To support the analysis, following datasets are prepared:
1) JBMUR administrative boundary (https://gadm.org/maps/IDN.html)
2) Landsat 5 Level 2 Collection 2 Tier 1 (https://developers.google.com/earth-engine/datasets/catalog/LANDSAT_LT05_C02_T1_L2)
3) Landsat 8 Level 2 Collection 2 Tier 1 (https://developers.google.com/earth-engine/datasets/catalog/LANDSAT_LC08_C02_T1_L2)
